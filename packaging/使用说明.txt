CYLT Launcher 0.1.0 — 开发预览版

安装：运行 MSI，选择目录。无需另外安装 .NET。支持 64 位 Windows。
使用：先进入账号管理选择账号，再在首页选择版本并点击开始游戏。
首次运行需联网下载 Minecraft 和匹配的 Java；已安装的离线游戏可从本地启动。
游戏默认位于 %LOCALAPPDATA%\CYLTLauncher\game，也可在启动设置中选择其他目录。

当前状态：
- 已验证 Minecraft 26.3 安装、自动 Java 下载和离线账号启动。
- 微软、离线、第三方账号入口均已实现。
- 默认微软应用仍缺 Minecraft 服务接入许可，正版登录目前不能完成。
- 第三方认证已通过模拟协议测试，尚未用真实服务器账号验证。
- Modrinth / CurseForge 提供资源搜索及项目页入口；CurseForge 需先配置获批的 API Key。
- 本版本暂不提供一键安装模组加载器或整合包。

“记住账号”默认关闭；开启后仅用当前 Windows 用户的 DPAPI 加密保存令牌，不保存密码。
CurseForge Key 只加密保存在填写它的电脑上，不会随安装包分发给朋友。
卸载保留游戏、存档和账号配置；可在程序中退出账号、清除已保存的 Key。
